# Achievle
Попытка геймификации вашей жизни. Сделайте из вашей рутины, задач или целей в игровые достижения, получайте опыт и закрывайте ваш список достижений на 100%. 
Вообще делал эту программу для себя, но может быть она кому-то тоже нужна.

## Возможности и примечания
- *Множество типов задач*: от ежедневных до испытаний и мастерства.
- *Гибкая настройка достижений*: описания, иконки, закрепление. Возможность делать их накопительными или поставить для них дедлайн. (в будущем будет больше возможностей)
- *Статистика*: отслеживайте завершённые достижения по типам, количество выполнений ежедневных достижений, активность за неделю.
- *Архив*: возможность спрятать незавершаемые (или нет) достижения
- *Локальное хранение*: все данные сохраняются на вашем компьютере (никакого облака)

## Скачивание
Скачайте ZIP, распакуйте его и запустите .exe файл в папке dist. 

## Где данные
Все данные сохраняются в файле 'quests.json' в той же папке, где запущено приложение (dist)  
Если надо, сделайте резервную копию этого файла, чтобы не потерять прогресс.
